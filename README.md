# 杭州大富翁 · Hangzhou Tycoon

以 2010—2013 年杭州楼市为背景的回合制地产经营游戏。一回合一个月，买地、加杠杆、扛调控。

这是 **M0 灰盒版本（v0.3）**：玩法和数值验证用，美术是几何占位，不代表最终品质。

## 现在能玩到什么

- **48 个回合**（2010.01 — 2013.12），四名玩家：你 + 3 个 AI
- 24 格环形棋盘，五个板块（西湖边 / 城西 / 城北 / 城东 / 滨江），16 宗地块
- 买地、升级（最高 Lv5）、收租、过路费
- **银行贷款**：可借可还，按月付息，负债计入净资产
- **历史事件**：2010.03 热钱涌入 → 2011.02 限购 → 2011.10 降价潮 → 2012.11 地铁 1 号线 → 2013.03 限售
- **地块按时间出让**：申花、三墩、下沙、丁桥分别在 2011—2013 年挂牌
- **限购会真的卡住你**：名下满 2 套就买不了，只能等政策到期
- **点功能格看牌堆**：点「机会」「命运」会列出这一格可能抽到的全部卡片与效果；点「银行」能看当前利率与你的可借额度
- **政策条可查详情**：顶部政策条上的每个标签，鼠标悬停（手机上点一下）会展开该政策/事件的生效时间、剩余月数和具体数值影响
- 自动存档（浏览器 localStorage），刷新可续玩


## 部署到 GitHub Pages

### 方式一：网页上传（不用装任何工具）

1. 在 GitHub 新建仓库，名字用小写英文，例如 `hangzhou-tycoon`，选 Public。
2. 进入仓库 → **Add file → Upload files**，把本目录下的**所有文件**拖进去（包括 `.nojekyll`，它是隐藏文件，Windows 资源管理器里要先开启"显示隐藏文件"）。
3. Commit。
4. 仓库 → **Settings → Pages** → Source 选 **Deploy from a branch** → Branch 选 `main`、目录选 `/ (root)` → Save。
5. 等 1—2 分钟，访问 `https://<你的用户名>.github.io/hangzhou-tycoon/`。

### 方式二：命令行

```bash
cd site
git init -b main
git add .
git commit -m "Hangzhou Tycoon M0"
git remote add origin https://github.com/<你的用户名>/hangzhou-tycoon.git
git push -u origin main
```

推送后在仓库 Settings → Pages 里按上面的第 4 步开启即可。

> 如果仓库名取 `<你的用户名>.github.io`，站点会直接挂在根域名 `https://<你的用户名>.github.io/`，更适合做正式站点。

### 自定义域名（可选）

1. 域名商处添加 CNAME 记录指向 `<你的用户名>.github.io`。
2. 仓库 Settings → Pages → Custom domain 填入域名。
3. GitHub 会自动生成 `CNAME` 文件，不要删。

## 上线前必须替换的占位符

`privacy.html` 和 `terms.html` 里有两处占位符，Google 广告账号审核时会看：

| 占位符 | 替换为 |
|--------|--------|
| `[运营主体名称 / Operator name]` | 你的名字或公司名（必须是一个明确的责任主体） |
| `[contact@example.com]` | 一个能收信的邮箱，建议用域名邮箱 |
| `[YYYY-MM-DD]` | 实际生效日期 |

## 接 Google 广告前的检查清单

- [ ] 站点已上线，能公网访问，HTTPS 正常
- [ ] 隐私政策、用户协议可从首页进入（页脚已有链接）
- [ ] 占位符全部替换完毕
- [ ] 站点有真实可玩内容（不能是空白页或"建设中"）
- [ ] 已注册 AdSense / Ad Manager 账号并提交站点审核
- [ ] 面向 EEA/UK 流量时接入 Google 认证的 CMP（TCF v2.2）
- [ ] 广告位不遮挡操作区、可跳过、游戏音频在广告前静音

## 文件说明

| 文件 | 作用 |

| `index.html` | 游戏本体（单文件，含全部逻辑与样式） |

## 已知问题

- AI 不会主动卖地止损，也不会为了抢地而加杠杆，在下跌行情里偏迟钝
- 数值是灰盒调参，四家净资产差距偏小，需要模拟器重标
- 没有音效，没有正式美术
