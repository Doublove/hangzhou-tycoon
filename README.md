# 杭州大富翁 · Hangzhou Tycoon

以 2010—2026 年杭州楼市为背景的回合制地产经营游戏。一回合一个月，四章十六年，买地、加杠杆、扛调控。

当前版本 **v1.1**：经济底层重做（V1.1 五条玩法修订），AI 按新经济重写。

## 能玩到什么

**结构**
- 4 章 × 204 回合：限购前夜（2010—2013）、G20 红利（2014—2017）、万人摇（2018—2021）、分化时代（2022—2026）
- 年轮地图：每章一圈 **26 格**（起点 1 + 地块 16 + 功能格 9），旧环沉降为收租层
- 章节间资产按净资产 40% 折算，保留 1 宗最贵地块作为「时代遗产」
- 6 个角色（杭铁头 / 温老板 / 码哥 / 阿莲 / 小笼包 / 王中介），各有被动技能
- 3 档 AI 难度：跟风型 / 算账型 / 老狐狸

**内容**
- 12 个区域、64 宗地块，按历史节点陆续挂牌
- 30 条历史事件：限购、限贷、降价潮、G20、亚运会、摇号、限价、烂尾、分化……
- 24 张机会卡 + 26 张命运卡（含 3 张会把你送进监狱的卡）
- 地块 Lv0—Lv5，租金率逐级 0.8% / 1.1% / 1.4% / 1.7% / 2.0%

**机制（V1.1 重点）**
- **过路费 Lv1 10%，逐级至 18%**（原 4%—10%）。一次落地约等于 10 倍月租
- **连片加成**：环上相邻地块同主，过路费 ×2。三连不叠乘，跨起点不算相邻
- **单次上限**：一次过路费不超过支付方净资产的 30%，超出部分「经调解减免」
- **经过起点**：月供 1 万 + 当前现金 3%（原为固定 150 万）
- **监狱**：踩中或被卡送进来，掷出偶数才能出狱；连续 3 次未中，第 4 回合强制释放
- **风景区**：第一章西湖风景区 / 第二章运河夜游 / 第三章亚运场馆 / 第四章良渚遗址，踩中掷 1D6 停留 1—6 回合，期间不能操作但租金照收
- 银行贷款：月息 0.6%，额度 = 净资产 × 60%，限贷期降到 40% 且加息
- 摇号：2018.04 起，热度 ≥ 60 的板块买地要抽签
- 限价：2021.08 起卖地收益封顶
- 烂尾：2022.05 起，城东/城北/临平/三江汇的在建地块可能停工
- 法拍：破产玩家的地块按 6 折被其他玩家接盘
- 股票：证券交易所可买卖「杭州楼市指数」
- 存档：1 个自动档 + 手动存档，刷新可续玩

**界面**
- 棋子为国际象棋造型（王 / 后 / 车 / 马），高度约为地块图标的 1.5 倍，当前回合的棋子会轻微浮动
- 日志栏固定 10 行，每名玩家开始行动时插入一条分隔行，向上翻看时暂停自动滚动

## 文件结构

| 文件 | 作用 |
|------|------|
| `index.html` | 页面骨架与样式 |
| `data.js` | 数据层：配置、区域、角色、棋盘、事件、卡牌、难度 |
| `game.js` | 逻辑层：回合、结算、AI、存档、渲染 |
| `privacy.html` / `terms.html` | 隐私政策 / 用户协议（中英双语） |
| `404.html` | 自定义 404 |
| `.nojekyll` | 跳过 Jekyll 处理 |

## 关键数值（调参入口）

| 参数 | 位置 | 当前值 |
|------|------|--------|
| 过路费率 | `game.js` `TOLL_RATE` | `[0, .10, .12, .14, .16, .18]` |
| 租金率 | `game.js` `RENT_RATE` | `[0, .008, .011, .014, .017, .020]` |
| 起点月供 | `data.js` `CFG.passGo` / `passGoRate` | 1 万 + 现金 3% |
| 过路费上限 | `data.js` `CFG.tollCap` | 净资产 30% |
| 监狱保底 | `data.js` `CFG.jailFailMax` | 3 次 |
| 地价标度 | `game.js` `buildRings` | 楼面价 ÷ 40 |
| 起始资金 | `game.js` `newGame` | 角色基准 × 章节起始年份的时代系数 |

## 已知问题

- 三档 AI 的差异主要体现在「是否看得懂连片」和「敢不敢加杠杆」，性格差异还不够明显
- 破产很少发生：AI 会主动卖地止损、单次过路费又有 30% 上限，四章跑下来通常无人出局
- 没有音效，美术仍是几何占位
- 地块详情里没有历史涨跌曲线
