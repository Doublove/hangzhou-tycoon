# 杭州大富翁 · Hangzhou Tycoon

以 2010—2026 年杭州楼市为背景的回合制地产经营游戏。一回合一个月，四章十六年，买地、加杠杆、扛调控。

当前版本 **v1.0**：完整四章内容已补齐，等你试玩后调平衡。

## 能玩到什么

**结构**
- 4 章 × 204 回合：限购前夜（2010—2013）、G20 红利（2014—2017）、万人摇（2018—2021）、分化时代（2022—2026）
- 年轮地图：每章一圈 24 格，旧环沉降为收租层，可在 HUD 看到「旧环资产」
- 章节间资产按净资产 40% 折算，保留 1 宗最贵地块作为「时代遗产」
- 6 个角色（杭铁头 / 温老板 / 码哥 / 阿莲 / 小笼包 / 王中介），各有被动技能
- 3 档 AI 难度：跟风型 / 算账型 / 老狐狸

**内容**
- 12 个区域、64 宗地块，按历史节点陆续挂牌
- 30 条历史事件：限购、限贷、降价潮、G20、亚运会、摇号、限价、烂尾、分化……
- 24 张机会卡 + 24 张命运卡
- 地块 Lv0—Lv5，租金率逐级 0.8% / 1.1% / 1.4% / 1.7% / 2.0%

**机制**
- 双收入线：月度租金 + 落地过路费
- 银行贷款：月息 0.6%，额度 = 净资产 × 60%，限贷期降到 40% 且加息
- 摇号：2018.04 起，热度 ≥ 60 的板块买地要抽签，热度越高越难中
- 限价：2021.08 起卖地收益封顶
- 烂尾：2022.05 起，城东/城北/临平/三江汇的在建地块可能停工
- 法拍：破产玩家的地块按 6 折被其他玩家接盘
- 股票：证券交易所可买卖「杭州楼市指数」
- 存档：1 个自动档 + 手动存档，刷新可续玩

## 本地预览

直接双击 `index.html`（纯静态，无依赖、可离线）。

或起静态服务：

```bash
python -m http.server 8080
# http://localhost:8080
```

**自动对战（回归测试用）**
- `?sim=1` 四名 AI 自动跑完整个战役
- `?sim=1&ch=2` 直接从第三章开局

| `index.html` | 页面骨架与样式 |

| `game.js` | 逻辑层：回合、结算、AI、存档、渲染 |

## 已知问题

- 数值是灰盒调参，四家净资产差距还需用模拟器校准
- AI 不会主动卖地止损（只在现金告急时被动卖），也不会为了抢地加杠杆
- 没有音效，美术仍是几何占位
- 地块详情里没有历史涨跌曲线
